## Project Features:
By the end of this course, implemented features: 
*   **Login system:** Secure authentication for faculty members to manage their profiles and student requests.
*   **Reporting system:** A comprehensive routine builder and PDF export feature that allows students to generate and download their weekly consultation reports.
*   **Faculty Search:** Real-time search functionality for students to find faculty by name or course.
*   **Request Management:** Dashboard for faculty to approve or decline student consultation appointments.
